<h3 id="드림핵">드림핵</h3>
<p>깃허브랑 벨로그 연결하고 워게임 한문제 겨우 풀었다..
예상대로 보안 공부는 처음이다 보니, 여러 부분에서 막혔다.</p>
<p>강의는 진법 파트랑 인코딩, 디코딩파트 했는데, 2학년 논리회로 수업에서 들어봤던 것이지만 생각보다 잊어버린 부분이 많더라. 그리고 워게임문제는 64se64 문제 풀었는데, html 문제의 소스코드 찾아서 아스키코드 찾고, 그걸 Base 64로 디코딩해서 DH{} 찾는 거였는데, 아예 제로베이스다 보니까 알고보면 이렇게 간단한 것인데도 문제 푸는데 한참 걸렸다. 하다가보면 좋아지겠지... </p>

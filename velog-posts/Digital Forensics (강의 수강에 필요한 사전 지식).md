Dream Biginner - 드림핵의 주요 학습 카테고리 소개 - Digital Forensics - 강의 수강에 필요한 사전 지식</p>
<ol>
<li><p>CLI (Command Line Interface) 환경에서 작업해본 경험있다</p>
</li>
<li><p>파일 이름이나 확장자 수정해봤다.</p>
</li>
<li><p>삭제된 파일을 복구하는 방법에 대해 관심을 가져본 적 있다.</p>
</li>
<li><p>컴퓨터에 어떤 디지털 흔적들이 남는지 굼금했다.</p>
</li>
<li><p>보안, 해킹, 사이버 범죄 수사에 대해 호기심 있다</p>
</li>
<li><p>로그(LOG) 파일이라는 말을 들어본 적 있다.</p>
</li>
</ol>
<ul>
<li>프로그램이나 시스템에서 발생한 사건을 시간 순서대로 기록해 놓은 파일</li>
</ul>
<ol start="7">
<li>암호화, 복호화, 해시가 무엇인지 알고 있다.</li>
</ol>
<ul>
<li>암호화(Encryption): 평문 → 알아볼 수 없는 암호문으로 변환
복호화(Decryption): 암호문 → 원래 평문으로 복원
해시(Hash): 데이터를 고정 길이의 값으로 변환. 일반적으로 원본 복원이 목적이 아님</li>
</ul>
<ol start="8">
<li>타임스탬프(Timestamp)가 무엇인지 안다</li>
</ol>
<ul>
<li>특정 사건이 언제 발생했는지를 나타내는 시간 정보
예: 2026-08-14 14:30:25
로그 파일에서 &quot;누가 언제 무엇을 했는지&quot;를 추적할 때 중요함.</li>
</ul>
<ol start="9">
<li><p>실행 파일(.exe) 같이 텍스트가 아닌 파일을 열어본 적 있다.</p>
</li>
<li><p>VM(가상 머신)을 사용해본 경험 있다.</p>
</li>
</ol>
